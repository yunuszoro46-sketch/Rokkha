# Rokkha Landing Page

This folder contains the standalone landing page for **ROKKHA.** matching the primary design specifications.

## Sections Included
1. **Header / Navbar:** Brand logo (shield), website title (`ROKKHA.`), and `Get Protected ->` call-to-action.
2. **Hero Section:**
   - Platform badge (`• NEXT-GEN PROTECTION PLATFORM`)
   - Main headline (`A Safeguard when needed`)
   - Value proposition description
   - Reliability statistics (`99.9% Reliability Rate` & `24 / 7 Active Monitoring`)
   - Interactive early access card (`Request Info & Early Access`) with form fields for Full Name, Email/Phone, Location/City, and Protection Requirement.
3. **Why Choose Rokkha Section:** 3 feature showcase cards:
   - Instant Response
   - Real-Time Updates
   - 24/7 Dedicated Support
4. **Footer:** Copyright, Legal, and Support links.
